# Moodle DevOps Lab

Laboratorio personal para aprender DevOps
aplicado a plataformas Moodle.

## Entorno
- Windows 11 Pro
- Ubuntu sobre WSL2
- Docker Desktop
- Git y GitHub

## Objetivos
1. Aprender Linux y Docker.
2. Administrar Moodle.
3. Dominar Docker Compose.
4. Automatizar pruebas y despliegues.
5. Aprender Kubernetes.
6. Monitorizar y mantener Moodle.
