# Práctica 01 — Operación de Moodle con Docker

## Objetivo
Comprender cómo se ejecuta Moodle con PostgreSQL
mediante contenedores Docker.

## Entorno
- Windows 11 Pro
- Ubuntu sobre WSL2
- Docker Desktop
- Moodle 4.5
- PostgreSQL

## Comandos utilizados
- docker ps -a
- docker volume ls
- docker logs
- docker inspect
- bin/moodle-docker-compose ps
- bin/moodle-docker-compose stop
- bin/moodle-docker-compose start
- bin/moodle-docker-compose restart

## Comprobaciones
- [X] Moodle accesible desde localhost:8000
- [X] Contenedores identificados
- [X] Logs revisados
- [X] Almacenamiento inspeccionado
- [X] Curso conservado tras stop/start
